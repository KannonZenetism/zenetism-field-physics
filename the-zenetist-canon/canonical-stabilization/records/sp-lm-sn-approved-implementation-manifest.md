# 8. Mathematical Preservation Boundary

A lexical or label correction does not carry mathematical standing merely because it appears near an equation.

Classify each approved correction before implementation as one of:

### A. Lexical-only

Prose changes.

Equations, symbols, operators, hypotheses, and mathematical claims remain unchanged.

### B. Label-only

A heading, legend, registered label, or descriptive name changes.

The mathematical object remains unchanged.

### C. Notational

An identifier, subscript, symbol, operator label, or displayed mathematical token changes.

This class requires express admission in the notational schedule.

### D. Mathematical

A domain, hypothesis, map, quantity, operation, equation, proof statement, inequality, limit, integral, or claimed result changes.

This class requires express admission in the mathematical schedule.

Codex must never move a correction from A or B into C or D by inference.
