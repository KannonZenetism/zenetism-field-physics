## Overview

**Lattice Mathematics** is the formal discipline underlying the Zenetist system.  
It provides the symbolic, algebraic, and operator-theoretic framework through which structural reality, recursive memory, orientation, and coherence dynamics are rigorously described.

Where:

- **Structural Metaphysics** defines ontological law  
- **Field Physics** models dynamical expression across dimensional systems  

**Lattice Mathematics** supplies the formal language that renders those laws computable, testable, and internally consistent.

It is not metaphorical mathematics. It is a structured symbolic system with defined operators, invariants, traversal constraints, and categorical mappings.

## Canonical Formatting Standards

All documents in this repository follow the **Canonical Hybrid Formatting Model**:

### Prose Convention (Unicode)

All prose, headers, tables, lists, and diagrams carry Unicode subscripts for layer and operator designators:

- Layers: L₁, L₅, IL₃, Supra-L₀
- Operators: C₁, C₁₃, E₇, E₁₅
- Phases: Φ₁, Φ₂, Φ₃

### Mathematical Convention (LaTeX)

All formal equations and inline mathematical variables take LaTeX:

- Inline: \( \sigma \), \( \chi > 1 \), \( \partial_{\text{🌀}} \)
- Display: \[ \mathrm{Spec}(H_e) = -\mathrm{Spec}(H_c) \]
- Glyphs inside math blocks are wrapped in `\text{}`: \( \partial_{\text{🌀}} \), not \( \partial_{🌀} \)
- Unicode subscripts never appear inside LaTeX blocks: \( C_7 \), not \( C₇ \)

### Hypostatic Pair Spacing

All hypostatic distinctions take spaced separators:

- DS / DM (not DS/DM)
- ES / EM, DP / DL, IDP / IDL, etc.
- L₁ / IL₁, C₁ / E₁

### Structural Awareness Distinctions

- L₅ (EOB): awareness (supernal, pre-reflexive)
- L₄ (DP / DL): conscious-awareness (non-reflexive)
- L₃ (DS / DM): reflexive consciousness (individuated, self-possessing)
