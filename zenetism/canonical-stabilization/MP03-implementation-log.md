## Soul and essence — deliberately preserved, not swept

MP03 carries its own governing note at lines 138–183, **Note on Soul and Essence Terminology**, which preserves the early poetic register and supplies the reading rule: L₄ / IL₄ through L₁ / IL₁ concern the Soul / Mind dyad; L₅ / IL₅, L₀, and Supra-L₀ concern essence; and where the document speaks of souls returning through supernal strata, reaching Aion, or saturating beyond the lattice, the precise reading is essences.

The Terminological Lockdown Protocol carves out exactly this case: Soul-language should not attach to Zenonic saturation **except when explicitly discussing legacy wording or correcting earlier terminology**. MP03's note is that explicit discussion, so the 102 soul instances stand as written. Sweeping them would destroy the poetic register the note exists to protect.

The note also uses **supernal strata** rather than supernal arc, which is already correct against MP08's Note on Supernal / Subversal.
